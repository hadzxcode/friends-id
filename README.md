Website ini dikembangkan sebagai landing page resmi untuk **Komunitas WhatsApp FRIEND ID**. Pengunjung dapat melihat informasi mengenai komunitas serta mengakses tautan untuk bergabung dengan tampilan antarmuka yang modern dan responsif.

---

## 🚀 Cara Menjalankan

1. Clone repository ini.

```bash
git clone https://github.com/hadzxcode/friend-id-landing-page.git
```

2. Masuk ke folder project.

```bash
cd friend-id-landing-page
```

3. Buka file **index.html** menggunakan browser.

Tidak memerlukan proses instalasi ataupun library tambahan.
